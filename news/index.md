# Changelog

## Changes in version 1.21.2

- Remove the legacy DoRothEA installation dependency. Classic CARNIVAL
  preprocessing now requires an explicit TF regulon; use a prepared
  CollecTRI regulon for new work.
- Retire
  [`load_tf_regulon_dorothea()`](https://saezlab.github.io/cosmosR/reference/load_tf_regulon_dorothea.md)
  with a clear migration error.

## Changes in version 1.21.1

- Declare Pandoc (\>= 2.8) as a system requirement for rendering
  vignettes.
